# 有机反应学习图谱

按反应类型组织的有机化学学习资料，支持分类阅读、组合搜索、反应比较和连续阅读。

## 使用

在仓库的 Releases 中下载 `有机反应学习图谱_分享包.zip`，解压后打开 `index.html`。保持两个 HTML 文件与 `图式/` 文件夹的位置关系，即可离线使用。请下载 Release 附件，GitHub 自动生成的 Source code 压缩包不包含完整学习资料。

- 570 条分类索引，489 个完整条目；同一反应通过交叉引用连接不同分类。
- 支持反应名称、正文文字、试剂别名及化学式搜索，可按大类、底物、条件和学习标记筛选。
- 40 个共用知识节点、52 组反应比较、14 个目标产物入口和立体结果对照。
- 点击图式可放大；打开 `连续阅读版.html` 可连续阅读或打印。

图片内部的文字尚未纳入全文搜索。学习标记仅供浏览参考，不代表考试频率。

## 参考书目

- 芦金荣：《有机化学复习指南与习题精选（第二版）》。
- 邢其毅、裴伟伟、徐瑞秋、裴坚：《基础有机化学（第4版）》上、下册。
