# 考研有机化学反应学习图谱 · Organic Reaction Atlas

这是个人在考研复习过程中，借助 ChatGPT 制作和整理的有机化学学习项目。希望把分散在各章节的反应，按反应类型重新归类，将反应式、机理、特点和共用规律放在一起，方便记忆、比较和查找，分享出来供大家学习交流。

内容涵盖亲核取代、亲核加成、亲电加成、亲电取代、消除、氧化、还原、不饱和键转化、自由基、重排、周环、重氮盐转化等类别，并通过交叉引用连接相关反应。

## 使用

在仓库的 Releases 中下载完整 ZIP 附件（`organic-reaction-atlas-v1.0.0.zip`），解压后打开 `index.html`。保持两个 HTML 文件与 `图式/` 文件夹的位置关系，即可离线使用。请下载 Release 附件，GitHub 自动生成的 Source code 压缩包不包含完整学习资料。

- 570 条分类索引，489 个完整条目；同一反应通过交叉引用连接不同分类。
- 支持反应名称、正文文字、试剂别名及化学式搜索，可按大类、底物、条件和学习标记筛选。
- 40 个共用知识节点、52 组反应比较、14 个目标产物入口和立体结果对照。
- 点击图式可放大；打开 `连续阅读版.html` 可连续阅读或打印。

图片内部的文字尚未纳入全文搜索。学习标记仅供浏览参考，不代表考试频率。
